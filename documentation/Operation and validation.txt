The author confirms successful operation of the cosine-response apparatus, firmware, desktop software and data acquisition. Retained measurements and plots document operation. Individual fault-injection tests and an independently reproduced executable build are not asserted.
The rotating source illuminates a stationary detector. Maintain detector alignment and operate within the Arduino input range. The separate optical saturation setup described in the supplement is not the Arduino acquisition circuit.
Historical V5.2.2 is preserved unchanged. Static review identifies that homing does not honour STOP; physical Start lacks a homed-position guard; HOME and LASER OFF can disrupt active state handling. Author confirmation of normal operation does not remove these code limitations. Do not treat these controls as a hardware emergency stop; isolate power if motion cannot be stopped through the controls. Use an enclosed scan plane and beam stop and keep clear of the moving arm.
